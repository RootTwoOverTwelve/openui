# Library

Reference notes for agents: how to reach the SLURM cluster, lab conventions,
a paper's style guide — anything you'd otherwise paste into a chat or copy
into a repo's CLAUDE.md.

- Drop Markdown files here. The first `# heading` is the display name.
- Only this README is tracked; everything else in the folder is ignored by git.
- In OpenUI: the **Library** button in the header browses and renders them;
  the book icon in a session's panel sends one to that agent, which then
  reads the file itself and applies what's relevant.
- These are notes, not a secret store: keep keys and passwords in
  `~/.ssh/config` or your environment and refer to them by name.
